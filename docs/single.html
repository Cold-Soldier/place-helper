格子摆放辅助器

解锁格子 · 添加物品 · 求解最优摆放

1 · 棋盘与解锁

直接点棋盘上的格子即可切换「已解锁 / 未解锁」。灰色斜纹 = 未解锁，物品不会摆在那里。
已解锁 0 格 未解锁 0 格

2 · 形状库（含 L 形）

自己画一个形状（最多 6×6）
点击格子拼出形状

3 · 物品清单 0 种

每行右侧的「可旋转 / 可镜像」可以单独控制这一种物品的摆放自由度。
物品总格数 0 可摆面积 -

4 · 求解

关掉「允许旋转」= 只能按你画出来的方向摆；关掉「允许镜像翻转」= 只能用旋转能达到的方向。
注意：2×2、1×2、3 格 L 这类形状的镜像本来就等于它的某个旋转， 所以对它们关掉镜像看不出区别（本来也不存在“被镜像”这回事）； 4 格 L、S/Z 形才是手性的，关掉镜像才真正少一半朝向。 结果区会标出每件物品的实际朝向，可以自己核对。

5 · 存档

配置会自动保存在浏览器本地，下次打开还在。
点格子解锁，右侧看方案
未解锁 已解锁 已摆放物品
